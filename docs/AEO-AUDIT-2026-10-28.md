# CLP Vriksha AEO Audit

**Audit date:** 2026-10-28  
**Scope:** Initial public-site and repository-configuration review  
**Status:** Baseline assessment; full crawl and Search Console performance data remain outstanding.

## Executive summary

CLP has a clear continuous-learning purpose, public learning pathways, an XML sitemap, an HTML sitemap, canonical URL checks, JSON-LD presence checks, and explicit crawler policies. These are useful foundations for answer-engine optimization (AEO) and generative-engine discoverability (GEO). They do not guarantee inclusion or citation in search or AI answers.

This is a baseline audit, not a claim that every public URL, schema type, or AI answer engine has been exhaustively tested.

## Initial AEO content acceptance checklist

For each important public landing page or article:

- State the topic and intended audience clearly near the beginning.
- Provide a concise, self-contained answer to the primary user question.
- Use descriptive headings and meaningful internal links.
- Cite credible primary sources for material factual claims.
- Distinguish established facts, opinion, forecasts and examples.
- Include original applied-learning examples when useful.
- Keep title, meta description, canonical URL, Open Graph metadata and structured data consistent with visible content.
- Use FAQ structured data only when eligible and when questions and answers are visible on the page; do not add schema solely to chase rich results.
- Ensure important content is available as crawlable HTML and is not hidden behind interaction or login unless intentionally restricted.
- Never auto-invent credentials, citations, statistics, authorship, or outcomes.

## Continuous validation design

Run repository checks on pull requests and pushes to the production branch, and run a scheduled public-site smoke test. A failure should create an actionable report with URL, check, evidence and suggested remediation. Safe deterministic changes may be proposed automatically on the same feature branch; content, security, privacy, canonical strategy, redirect and crawler-policy changes require human review.

## Limitations

This report does not claim a complete crawl of all live URLs, access to private Search Console reports, observed AI citations, or confirmation that GitHub branch protection is active. Those require separate live or account-level evidence.
